# H100 State-TTT 主线：输运、归一化、可信 Sink 与稀疏地址

日期：2026-10-15。阶段：设计推导和 CPU 小矩阵代数检查，未实现到生产训练、未同步服务器、没有新视频或质量提升结论。参照分支 `codex/ttn-dual-psi-fp8`，提交 `54c2d138a56a37381140c8fcd1ee8cd567649f0f`。

## 1. 固定主线与实际轴向

保留相机条件 Cayley 输运 S、TTT 直接修改 S、完整序列外循环梯度。新增组件必须服务同一个关联记忆，而不是独立输出再相加。

当前 `Read = Q S`，`S` 的第一维是地址维，第二维是 value/输出维。`CayleyFactors.right(S)` 是 `S R`，实际转动输出维；并不是在地址维执行 `R S`。

因此可以保持稀疏地址不转动，同时把 S 的值侧和 Sink 的值侧视图一起输运。这是潜在通道变换的一致性，不是已证明的三维相机等变性。

## 2. 一套记忆、一个归一化读出

每个 head 维护：

- `S_t`：可塑内容矩阵，由 TTT 直接更新。
- `z_t`：地址支持统计，与内容的基础写入采用同一权重；它不是另一个随意学习的输出门。
- `(C_0,z_0,mu_0)`：仅来自实际观测首帧的规范 Sink，后续生成不得覆写。
- `P_t`：累计的值侧 Cayley 变换；规范 Sink 不改写，当前视图为 `C_0 P_t`、`mu_0 P_t`。

下文先令 Sink 的位置标签固定。第 4 节的结构化特征进一步允许用确定的 `H_t` 精确改变压缩 Sink 的虚拟时间标签，此时当前视图为 `H_t^T C_0 P_t`、`H_t^T z_0`。这不是额外的可学习路由器。

定义行向量地址 `a(q)=phi(q)`，一个候选读出为：

`Y_t(q) = [a(q)(S_t + kappa_t C_0 P_t) + eps mu_0 P_t] / [a(q)(z_t + kappa_t z_0) + eps]`。

规范 Sink 是独立来源，但使用同一个读出和同一个更新目标。`kappa_t` 在内容、分母两侧必须一致。预算可按有效写入计数校准，避免首帧随历史长度增长而消失；不要用“所有特征坐标之和”作为旋转不变的计数。实际每个查询的 Sink 支持比例必须测量，不能把整体预算当成逐查询保证。

在 TTT 任意修正 S 之后，S 不再一定是正权重 KV 外积和。这里不声称最终输出是历史 V 的凸组合，也不声称归一化自动限制任意 S 的输出幅度。

## 3. 归一化与 Cayley 的精确兼容关系

记增广状态 `T=[S,z]`，则输运采用：

`T^- = T diag(R,1) = [S R,z]`。

z 是地址支持，不跟随 value 通道旋转。Sink 当前视图同样在值侧输运。在固定地址 q 下：

`Read(q;S R,C_0 P R,z,z_0,mu_0 P R) = Read(q;S,C_0 P,z,z_0,mu_0 P) R`。

这是可以严格验证的兼容性。不能对整个 `[S,z]` 使用原来的 D 维旋转，也不能把分母向量按 value 旋转后再要求其保持正值。

规范 Sink 的只读含义是后续事务不覆写其数值。训练时仍保留从读出回到首帧编码的外循环图；不能为了缓存而把整条 Sink 路径 detach。

## 4. 稀疏地址必须同时考虑 RoPE 和更新算子

直接在 RoPE 之后逐坐标 `ReLU(x-tau)` 会破坏其共同相位平移下的等变关系；先 ReLU 再 RoPE 又不保证归一化核非负。因此不建议把六案例里的标量 ReLU 映射直接搬进主线。

一个可推导的候选是按实际 RoPE 二维通道对分组。令 `u=(u1,u2)`，`r=sqrt(||u||^2+eps_r^2)`，构造：

`phi_j(u) = g_j(r) (r,u1,u2)`，`g_j(r)>=0` 只依赖旋转不变的半径。

稀疏候选可用 `g_j(r)=ReLU(r-tau_j)/r`；再做旋转不变的整体 L2 尺度归一化。全零地址采用明确的观测均值回退并记录发生率，不能静默除零或宣称这类样本仍有有效地址梯度。

对任意二维旋转 O：

- `phi_j(u O)=phi_j(u) diag(1,O)`；
- `phi_j(u) phi_j(v)^T = g_j(r_u)g_j(r_v)(r_u r_v + u dot v) >= 0`。

这还提供一个与长期 Sink 直接相关的用途。若实际 RoPE 的时间重定位对应二维旋转 O，则提升空间中的 `H=diag(1,O)` 可直接作用于压缩统计：`C_0' = H^T C_0`、`z_0'=H^T z_0`。它与逐 token 重新旋转原 K、重新计算特征、再聚合 KV 的结果一致，不需要保存并反复重编码完整历史 KV。多组情况取块对角 H。

因此，在此候选中可同时做位置轴上的确定变换和 value 轴上的 Cayley 变换：`C_0^(t)=H_t^T C_0 P_t`。对应查询也同样重定位时，初始观测读回目标仅需乘 P_t。H_t 改的是虚拟位置标签，不能冒充真实三维相机几何。H_t=I 与时间重定位是必须比较的两种策略；实际选择及训练/推理一致性需要验证，代数等价不保证重定位能改善质量。

因此地址的标量坐标可以有负数，但两地址形成的核非负。z 也无需逐坐标非负，分母的有效正性来自它确实是这些地址的非负加权和。所有头的 RoPE 配对布局须按实际实现验证，不可默认任意相邻两个标量都是同一个旋转对。

112 个输入通道变为 56 个三维组，即 168 维地址，S 为 `168x112`，不是旧的 `112x112`。这是候选表示变化，需要独立配置和检查点身份。

此类 norm/Lorentz-cone 正核提升已有文献，不作为独创新特征映射。它的作用是为我们的输运和稀疏地址提供明确的兼容关系。它也有容量与背景相似性限制，不能因核非负就声称能区分任意历史。

更重要的是，原来的稠密投影 `A A^T` 可能重新耦合不相交的稀疏地址：`a_i a_j^T=0` 并不推出 `a_i A A^T a_j^T=0`。

第一版建议采用全地址直接梯度，或严格按旋转组保持结构的正定对角/块标量预条件；不再对地址施加任意稠密 rank64 投影。这保留 TTT 直接更新 S，但改变了旧的低秩优化器，是需要单独消融的算法选择。

## 5. 把基础绑定与直接 TTT 校正合成一次事务

一个可供验证的事务定义是：

1. `S^- = S_prev R`，`z^- = z_prev`，构造 Sink 的当前值侧视图。
2. 基础关联写入 `B = phi(K)^T W V`，`m = phi(K)^T w`。
3. 构造 `S_base=S^-+B`，`z_new=z^-+m`。
4. 在下述同一个归一化目标上对 `S_base` 做一次 TTT 修正，得到 `S_new`。
5. Clean 事务提交 S、z 和累计输运；Noisy 的临时状态与临时统计一同丢弃，不能随 solver 次数累加。

基础绑定是有定义的无在线适配对照。TTT 则修正绑定误差。不要在这次修正之后再重复执行一遍旧 Correct；旧 Correct 的残差修正角色应并入新目标，避免两套更新不一致。

这不是与旧 H100 数学等价的工程补丁。S 现在是归一化读出的内容参数；不能只给旧 `Q S` 挂上分母、保持旧 `K S-V` 目标不变。

## 6. 一个内循环目标约束可塑性和可信源

`L_inner = L_current_LOO + lambda_obs L_observed_recall`。

- 当前项：通过真正使用的归一化 Read 重建 V；从当前 token 的内容和支持量中同步排除自身贡献。若 kappa 使用当前计数，LOO 也必须相应重算该计数，或明确采用只依赖旧历史的固定预算。
- 可信项：保存少量真实首帧查询及其初始参考输出，要求后续完整读出仍能回答这些查询。参考输出按同一值侧 P_t 输运。这提供当前数据拟合与保持可信历史之间的明确权衡。
- 保存参考目标可 stop-gradient；只读统计和被学习的读出路径仍需保留外循环梯度。参考只是初始观测特征的一致性目标，并不等于物理真值或独立教师质量保证。
- 查询/目标采用固定小网格子集即可，不引入 slot、MoE 或另一个检索网络。先保持外循环 flow loss 不变，不同时添加多个辅助外损失。

在固定 z、kappa 和地址下，Read 对 S 为线性映射，所以以上两项仍是关于 S 的加权二次目标。令实际归一化设计矩阵为 X，则可用它计算梯度和 Hessian trace；不是继续使用原始 K 的曲率。步长受该正半定二次目标的曲率上界控制时，可以保证该次内循环目标不增。

这个下降结论不意味着未来 velocity MSE 或长视频质量改善。K 处拟合与 Q 处使用的差距也仍需外循环和实际任务验证。

## 7. 需要承认的代价和失败路径

- 地址宽度增加 50%，同精度下单个 S 从约 4.79 MiB/rank 增至 7.18 MiB/rank（5 anchors、20 heads）；Sink、累计输运和有限 probes 另占空间。完整梯度的激活、重算和 CPU offload 才是更大的 RAM 项，不能凭持久状态小就保证运行安全。
- 稀疏特征仍可使用稠密 GEMM，不自动带来速度提升。移除低秩 QR 与增加地址宽度的净吞吐必须实测。
- Sink 可以被其他有符号内容抵消；只读来源并不保证最终网络使用它。需要真实输出贡献和未来目标误差的配对干预。
- 径向稀疏偏向高能量通道组，可能删掉低能量但重要的语义；门控密度和丢弃信息不能只用稀疏率判断。
- RoPE 和值侧输运的一致性只适用于明确的线性记忆子步；不扩展为整个网络的三维几何或长程稳定性定理。
- 旧检查点不能作为新记忆规格的 exact resume。主干参数可在明确的新实验中继承，但不是无损迁移。

## 8. 最小验证顺序

先完成 CPU 数学检查，再使用真实 H100 权重捕获的 Q/K/V 和连续历史验证，不再用原 SANA 特征替代最终结论。

1. 轴向输运等式、RoPE 共同平移等式、压缩 Sink 重定位与逐 token 重建的一致性、核非负、常值基础绑定、空支持、精确 LOO、归一化目标梯度/曲率、完整外循环梯度。
2. 同样 168 维和同样预算下，对比无稀疏门的映射与径向稀疏映射，避免把容量增大算成稀疏收益。
3. 基础绑定与 TTT 修正对照都写入同样历史；无 TTT 不应同时被偷偷删除历史内容。
4. 独立 Sink 预算和保护项分别做干预，记录跨多次写入的可信历史读回、当前/未来 velocity MSE、颜色/幅度漂移与真正 rollout。
5. 验证后再讨论新训练；本阶段不替换正在运行的模型。
